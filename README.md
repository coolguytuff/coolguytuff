## 🧬 How I think about building

```mermaid
flowchart LR
    A[Idea] --> B[Prototype]
    B --> C[Test]
    C --> D{Works?}
    D -- No --> E[Debug / Rethink]
    E --> B
    D -- Yes --> F[Automate]
    F --> G[Evaluate]
    G --> H[Improve]
    H --> I[Ship]
    I --> A
```

> The interesting part of AI isn't getting one impressive answer. It's building systems that remain useful **after the first answer**.
